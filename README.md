# Digi-Cam-video-Converter
AVI to MP4 Converter

## HOW TO USE

but first here are things u need to have
1. you need to download ffmpeg, here is the link https://ffmpeg.org
   this is the app that convert any file you want into any format that you want it to be.
   but for now i will be focusing in AVI to MP4 since most digicam uses AVI file format.

2. after ffmpeg is downloaded, go to your file explorer and create a new folder.

3. add the ffmpeg.bin file inside the folder.

4. now from the folder create a notepad or download my "convert.bat" file.
   if you have choose to create a notepad please copy everything that is inside my "covert.bat" file

5. now put your desired AVI file that you want to convert in the folder.

6. and now run this .bat file in cmd and ur done.
   in the folder it will separate and create a new folder that is called "Converted" and there will be you MP4 converted videos.
